# ふたつのメモ — Edge拡張
## インストール
1. Edgeで edge://extensions を開きます。
2. 「開発者モード」をオンにします。
3. 「展開して読み込み」を選び、この edge_memo フォルダーを指定します。
4. ツールバーの拡張機能から「ふたつのメモ」を開きます。ピン留めすると便利です。

## 使い方
- ツールバーのアイコンを押すとサイドバーにメモが開きます。Webページをクリックしても閉じず、ページとメモを並べて使えます。閉じるときはサイドバーの閉じるボタンを押してください。
- 起動時は常に「一時メモ」が開きます。入力内容は自動保存され、閉じても残ります。
- 「通常メモとして保存」で一時メモを通常メモにコピーできます。元の一時メモは残ります。
- 通常メモは新規登録・編集・削除・検索できます。編集は「保存する」で確定します。
- エクスポートは一時メモと全通常メモをJSONファイルに保存します。
- インポートはこの拡張が出力したJSONに対応します。通常メモは追加、一時メモは末尾に追加します。繰り返しインポートすると重複します。
- データはこのブラウザープロファイル内に保存されます。同期・外部送信はありません。拡張を削除する前にエクスポートしてください。
- 更新後は拡張一覧の再読み込みボタンを押してください。
- 1.2.0への更新も、`edge://extensions` で既存の「ふたつのメモ」の再読み込みボタンを押してください。保存データを引き継ぐため、削除して入れ直す必要はありません。

## 大きな画面とHTMLバックアップ
- ヘッダーの「大きな画面で開く」でブラウザーのタブに編集画面を開きます。拡張と同じ保存データを使用します。
- 「HTML保存」で一時メモと全通常メモを1つのHTMLファイルに保存します。
- 保存したHTMLはダブルクリックするか、ブラウザーへドラッグして開けます。拡張がなくても、ネット接続がなくても本文を閲覧できます。
- HTMLは出力時点の閲覧用です。編集や拡張への復元には「JSON保存」を使用してください。
- 通常メモの編集中は先に「保存する」を押してください。未保存の内容はバックアップに含まれません。
